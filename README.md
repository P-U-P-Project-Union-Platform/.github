#  P U P - Project Union Platform

**PUP(Project Union Platform)**은 연암공과대학교 SW학과 학생들이 만든 다양한 **개인/팀 프로젝트를 공유**하고, 서로의 작업물을 열람하며 **피드백**과 **협업**의 기회를 나눌 수 있는 플랫폼입니다.

##

##  목적

> 프로젝트를 통해 배우고, 성장하고, 함께 나누는  
> **SW학과만의 오픈 프로젝트 커뮤니티**를 구축합니다.

##

##  기술 스택

| 분야 | 기술 |
|------|------|
| **Backend** | NestJS |
| **Frontend** | React(Vite) |
| **Database** | MySQL |
| **CI/CD** | Git, GitHub Actions |
| **Deployment** | Docker, Docker Compose |

##

##  핵심 기능

###  프로젝트 공유
- 프로젝트 등록 (제목, 설명, GitHub 링크, 기술 스택 등)
- 이미지 썸네일 업로드
- 프로젝트 카테고리 및 태그 분류
- 키워드 및 해시태그 기반 검색

###  사용자 기능
- 학교 이메일 인증 기반 회원가입/로그인
- 사용자 프로필 (닉네임, 전공 분야, 관심 기술)

###  커뮤니티 기능
- 좋아요 및 댓글 기능
- 북마크(찜) 기능
- 프로젝트 팀원 태그 및 기여자 관리

##

##  향후 기능 제안

- 🔍 프로젝트 해시태그 기반 필터링
- 🧑‍💻 팀원 모집 및 지원 기능
- 📝 프로젝트 리뷰 및 평가 시스템
- 📊 사용자 활동 통계 대시보드
- 🔔 알림 기능 (댓글, 좋아요 등)
- 📁 프로젝트 PDF 파일 등 첨부 기능

##

##  대상 사용자

- 연암공대 SW학과 재학생/졸업생
- 포트폴리오를 정리하고 싶은 개발자
- 협업 또는 팀원을 찾고 싶은 학생
- 친구들의 프로젝트를 구경하고 피드백하고 싶은 학우
